# Marketing Attribution & ROI Dashboard

## Overview

This project analyzes marketing campaign performance
using:

- Python
- Pandas
- SQL
- Power BI

The objective is to:

- Analyze campaign spend
- Calculate KPIs
- Perform attribution modeling
- Measure ROAS
- Build an interactive dashboard

---

## Datasets

1. Ad Spend Data
2. Web Analytics Log
3. CRM Conversion Data

---

## KPIs

- Total Spend
- Total Revenue
- CTR
- CPC
- CAC
- ROAS

---

## Attribution Models

- First Touch Attribution
- Last Touch Attribution
- Revenue Attribution
